En enfärgad yta för skärmtest

Förhandsvisningen börjar med färgen #FF0000. I helskärm fyller den valda färgen hela testytan.

Det här kan du kontrollera

Röd skärm

Leta efter punkter som förblir mörka eller får en annan färg mot rött.

Så kontrollerar du bildskärmen

  1. Öppna förhandsvisningen på skärmen du vill kontrollera och använd din vanliga ljusstyrka.
  2. Titta på mitten, hörnen och kanterna. Växla färg för att jämföra samma punkt.

Använd knappen längst ned till höger i förhandsvisningen för att visa färgen i helskärm. Klicka eller tryck på skärmen, eller tryck på Esc för att avsluta.

Det här kan du titta efter

  • SvartLeta efter små prickar som fortsätter lysa.
  • VitSe efter mörka punkter, fläckar och ojämn ljusstyrka.
  • Rött, grönt och blåttKontrollera samma punkt i var och en av grundfärgerna.
  • GråttJämför om ljusstyrkan eller färgtonen skiftar över testytan.
