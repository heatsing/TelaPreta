Så använder du verktyget

  1. Öppna klockan i helskärm eller välj ”Pausa” för att hålla tiden stilla vid en inspelning.
  2. Klicka eller tryck på förhandsvisningen eller på ”Helskärm”.
  3. Klicka eller tryck på scenen eller ikonen för att avsluta. Med tangentbord kan du trycka på Esc.

Så kan du använda scenen

Visa klockan på en extra bildskärm så att tiden syns från hela rummet.

Vanliga frågor

Kan klockan visa en annan tidszon?

Klockan följer enhetens valda tidszon. Vill du byta tidszon använder du systeminställningarna.
