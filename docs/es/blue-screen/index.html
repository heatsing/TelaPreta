Un color uniforme para probar el monitor

La vista previa se abre con el color #0000FF. En pantalla completa, el color ocupa toda la zona de prueba.

Qué debes observar

Pantalla azul

Busca puntos oscuros o zonas de otro tono en el fondo azul uniforme.

Cómo comprobar el monitor

  1. Abre la vista previa en el monitor que quieras revisar y usa el brillo habitual.
  2. Revisa el centro, las esquinas y los bordes. Alterna los colores para comparar el mismo punto.

Usa el botón de la esquina inferior derecha de la vista previa para ver el color a pantalla completa. Haz clic, toca la pantalla o presiona Esc para salir.

Qué revisar con cada color

  • NegroBusca puntos que se queden encendidos y revisa las esquinas del panel.
  • BlancoObserva puntos oscuros, manchas o cambios de brillo.
  • Rojo, verde y azulAlterna los colores primarios para comprobar el mismo punto.
  • GrisCompara el tono entre distintas zonas del monitor.
