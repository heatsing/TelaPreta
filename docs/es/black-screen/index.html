¿Qué es una pantalla negra online?

Es una herramienta gratuita que muestra un fondo negro puro (#000000) en el navegador. Puedes usarla para ver puntos luminosos, oscurecer una segunda pantalla o generar una imagen negra para tu móvil.

Para qué sirve una pantalla negra

Comprobar los píxeles del monitor

Empieza por el negro para ver si hay algún punto que se queda encendido. Cambia a blanco para revisar los píxeles que siempre se ven oscuros.

Comprobar el negro de un panel OLED

Los píxeles OLED pueden apagarse para mostrar el negro. Esto puede reducir el consumo del panel. La autonomía depende también del brillo, el modelo y las aplicaciones que estén en marcha.

Ver el polvo antes de limpiar

Con la luz de una ventana de lado, un fondo oscuro puede resaltar el polvo y las huellas. Consulta cómo limpiar el monitor en las instrucciones de la marca.

Atenuar un segundo monitor

Deja un fondo negro en la pantalla auxiliar durante una presentación. Para descansar la vista, haz una pausa lejos del monitor.

Cómo comprobar un monitor con una pantalla negra

  1. Arrastra la ventana al monitor que quieras revisar y amplíala si necesitas más espacio.
  2. Mira si se queda encendido algún punto blanco o de color. Comprueba si hay polvo en esa zona.
  3. Pasa a blanco, rojo, verde y azul para ver cómo se comporta el mismo punto.

Usa el botón de la esquina inferior derecha de la vista previa para ver el color a pantalla completa. Haz clic, toca la pantalla o presiona Esc para salir.

Qué revisar con cada color

  • NegroBusca puntos que se queden encendidos y revisa las esquinas del panel.
  • BlancoObserva puntos oscuros, manchas o cambios de brillo.
  • Rojo, verde y azulAlterna los colores primarios para comprobar el mismo punto.
  • GrisCompara el tono entre distintas zonas del monitor.

Cómo descargar un fondo negro en PNG

Elige Full HD (1920 × 1080) o 4K UHD (3840 × 2160) para una imagen negra horizontal. Para el móvil, selecciona el formato vertical de 1080 × 1920. Pulsa “Descargar PNG” para guardar la imagen.

Preguntas frecuentes

¿Cómo pongo una pantalla negra en el navegador?

Abre la herramienta y selecciona Negro. La vista previa se pondrá negra.

¿La pantalla negra apaga el monitor?

El monitor sigue encendido y muestra el color negro. Usa el botón o los controles de energía del dispositivo para apagarlo.

¿Sirve para una prueba de píxeles muertos?

Puedes detectar puntos que se quedan encendidos sobre negro. Para encontrar un píxel oscuro, comprueba la pantalla con blanco y RGB.

¿Cómo descargo una pantalla negra vertical para el móvil?

Selecciona el formato Móvil y pulsa “Descargar PNG”. El archivo mide 1080 × 1920 píxeles.

¿El fondo negro ahorra batería?

Puede reducir el consumo de una pantalla OLED o AMOLED. La luz de fondo de un LCD suele seguir encendida.

Prueba otro color de pantalla

Con un fondo blanco puedes revisar si algún punto se queda oscuro.
