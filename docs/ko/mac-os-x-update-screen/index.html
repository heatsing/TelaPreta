사용 방법

  1. 시간과 시작 진행률을 지정한 후 「다시 시작」을 누르세요. 원하는 숫자에서 멈추려면 「일시 정지」를 누르세요.
  2. 미리보기를 클릭하거나 터치하세요. 「전체 화면」 버튼으로도 열 수 있습니다.
  3. 화면이나 종료 아이콘을 누르면 전체 화면이 닫힙니다. 키보드에서는 Esc 키를 누르세요.

활용 예시

이전 버전의 Mac 사용법을 설명할 때, 진행률을 고정하고 화면에 보이는 항목을 차례대로 설명할 수 있습니다.

자주 묻는 질문

Mac 컴퓨터에서만 실행되나요?

지원되는 브라우저에서 열면 Mac OS X가 설치되지 않은 기기에서도 시뮬레이션을 볼 수 있습니다.
