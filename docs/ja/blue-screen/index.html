青色画面をオンラインで表示

単色 #0000FF を全画面で表示してモニターを確認したり、同じ色のPNG画像を保存したりできます。

画面プレビュー

#0000FF

画面の色

黒白赤緑青グレー

有効なカラーコードを入力してください。例：#336699

モニター確認用の単色表示

プレビューの初期色は #0000FF です。全画面にすると、選んだ色がテスト領域全体に表示されます。

確認するポイント

青色画面

青い面に暗い点、色の異なる点、色ムラがないか確認します。

モニターの確認方法

  1. 確認したいモニターでプレビューを開き、明るさを普段の設定にします。
  2. 中央、四隅、端を確認し、色を切り替えながら同じ位置を見比べます。

プレビュー右下のボタンを押すと、選んだ色が全画面で表示されます。画面をクリックまたはタップするか、Esc キーを押すと終了します。

色ごとのチェックポイント

  • 黒点灯したままの輝点や、液晶画面の端の明るさを見ます。
  • 白黒点、色ムラ、明るさが異なる部分を探します。
  • 赤・緑・青三原色を切り替えながら、同じ位置の見え方を比べます。
  • グレー中央と周辺で、色や明るさに差がないか確認します。

PNGをダウンロード

解像度を選んでPNGをダウンロードすると、プレビューに表示中の色が画像になります。
