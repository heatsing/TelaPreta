使い方

  1. 「次のひとこと」を押して表示したい文章を選んでから、全画面にします。
  2. プレビューをクリックまたはタップするか、「全画面表示」を押します。
  3. 全画面にしたら、観客の席から見て改行が自然かを確認します。文章を変えるときは操作欄に戻ります。
  4. 画面または終了アイコンを押すと元のページに戻れます。キーボードの Esc キーでも終了できます。

ツールについて

用意された短い文章を一つずつ表示します。「次のひとこと」で順番に進み、最後の文章の次は最初に戻ります。

よくある質問

文章は自動で切り替わりますか？

選んだ文章はそのまま表示されます。別の文章を見たいときは全画面を終了し、「次のひとこと」を押します。

自分で考えた文章を入れられますか？

「次のひとこと」で用意された文章から選びます。自由な文を表示する場合は、スライドなどで用意します。

全画面表示でもブラウザーのバーが見えるのはなぜですか？

端末とブラウザーが対応していれば、画面全体に表示されます。全画面が許可されない場合は、ブラウザー内で見えている領域いっぱいに表示します。画面をクリック・タップするか、Esc キーを押すと戻れます。

活用例

ワークショップの休憩表示

ワークショップの休憩時間に、離れた席からも読みやすい短い文章を映せます。

読書会の導入

テーマに合う一文を選んで、参加者が読み終わるまで表示します。そのあとで全画面を閉じ、話し合いに移れます。
