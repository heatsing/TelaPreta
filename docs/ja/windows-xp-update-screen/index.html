使い方

  1. 撮影時間に合わせて更新時間と開始時の進捗率を入力し、「設定を適用して再生」を押します。
  2. プレビューをクリックまたはタップするか、「全画面表示」を押します。
  3. 画面または終了アイコンを押すと元のページに戻れます。キーボードの Esc キーでも終了できます。

活用例

懐かしいパソコンを題材にした映像で、更新作業の場面を作れます。

よくある質問

Windows XP の起動画面も表示できますか？

このページは更新の進捗を表示します。起動時のアニメーションは、一覧にある Windows XP 起動画面で表示できます。
