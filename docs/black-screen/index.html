O que é uma tela preta online?

É uma ferramenta gratuita que mostra um fundo preto puro (#000000) no navegador. Você pode usá-la para ver pontos que continuam acesos no monitor, deixar a segunda tela escura por alguns instantes ou gerar um fundo preto no tamanho que precisa.

Para que serve uma tela preta?

Ver pontos brilhantes no monitor

Abra o preto e observe se algum ponto branco ou colorido continua visível no mesmo lugar. Depois, compare com o branco e as cores primárias.

Conferir um painel OLED ou AMOLED

Um pixel OLED pode apagar para exibir preto puro. Isso pode reduzir o consumo do painel enquanto o fundo preto está aberto. A autonomia também depende do brilho e do que o aparelho está fazendo.

Localizar poeira e marcas de dedo

Sob luz lateral, um fundo escuro pode realçar marcas na superfície. Na hora de limpar, siga as orientações do fabricante do seu monitor.

Escurecer uma segunda tela

Abra o fundo preto no monitor secundário durante um filme ou uma apresentação. Para descansar os olhos, faça uma pausa olhando para longe da tela.

Como testar o monitor com uma tela preta

  1. Arraste a janela para o monitor que quer verificar e amplie a janela do navegador para ter uma área de teste maior.
  2. No fundo preto, procure pontos claros. Se encontrar um, anote a posição e verifique se há sujeira na superfície.
  3. Compare o mesmo ponto sobre branco, vermelho, verde e azul. Se ele aparecer sempre na mesma posição, consulte a política de pixels do fabricante.

Use o botão no canto inferior direito da prévia para ver a cor em tela cheia. Clique ou toque na tela, ou pressione Esc para sair.

O que observar em cada cor

  • PretoVeja se algum ponto continua aceso. No LCD, observe também as bordas.
  • BrancoProcure pontos escuros, manchas e diferenças de brilho.
  • Vermelho, verde e azulCompare um mesmo ponto nas três cores primárias.
  • CinzaProcure áreas com tons diferentes em um fundo intermediário.

Como baixar uma imagem preta em HD, Full HD ou 4K

Selecione a resolução e clique em “Baixar PNG”. Escolha HD (1280 × 720) ou Full HD (1920 × 1080) para um fundo de computador. Para uma imagem em 4K, selecione 3840 × 2160. A opção Celular gera um PNG vertical de 1080 × 1920.

Perguntas frequentes

Como deixar a tela preta no navegador?

Abra esta página e mantenha a cor Preto. Se estiver usando outro monitor, arraste a janela para ele.

A tela preta é igual a desligar o monitor?

Com esta ferramenta, o monitor continua ligado exibindo uma cor escura. Para desligar a tela, use o botão do aparelho ou as configurações de energia.

Uma tela preta ajuda a encontrar pixels queimados?

O fundo preto ajuda a ver pontos que continuam brilhando. Para procurar pixels que ficam sempre escuros, comece pelo fundo branco e compare com RGB.

Posso baixar uma tela preta em 4K?

Sim. Escolha 4K UHD para salvar um PNG preto de 3840 × 2160 pixels.

O fundo preto economiza bateria do celular?

Pode reduzir o consumo do painel em celulares OLED ou AMOLED. Em telas LCD, a iluminação de fundo costuma continuar ligada.

Experimente outra cor de tela

Compare com um fundo branco para conferir pontos escuros e áreas com brilho irregular.
