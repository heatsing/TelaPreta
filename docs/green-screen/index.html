Uma cor uniforme para testar a tela

A prévia começa com a cor #00FF00. Em tela cheia, a cor ocupa toda a área de teste.

O que observar

Tela verde

Veja se algum ponto aparece mais escuro ou com outro tom de verde.

Como verificar o monitor

  1. Abra a prévia no monitor que quer testar e use o brilho habitual.
  2. Observe o centro, os cantos e as bordas. Alterne as cores para comparar o mesmo ponto.

Use o botão no canto inferior direito da prévia para ver a cor em tela cheia. Clique ou toque na tela, ou pressione Esc para sair.

O que observar em cada cor

  • PretoVeja se algum ponto continua aceso. No LCD, observe também as bordas.
  • BrancoProcure pontos escuros, manchas e diferenças de brilho.
  • Vermelho, verde e azulCompare um mesmo ponto nas três cores primárias.
  • CinzaProcure áreas com tons diferentes em um fundo intermediário.
