使用方法

如何检查显示器

  1. 在要检查的显示器上打开预览，将亮度调到平时使用的水平。
  2. 观察中央、四角和边缘，切换颜色时对比同一个位置。

点击预览右下角的按钮，即可全屏显示当前颜色。点击或轻触画面，或按 Esc 退出。

不同底色可以看什么

  • 黑色观察有没有一直亮着的小点，顺便看看 LCD 面板边缘的亮度。
  • 白色查看固定暗点、色斑和亮度不均。
  • 红、绿、蓝轮流比较同一个点在三种原色下的表现。
  • 灰色查看屏幕中央和边缘的明暗或颜色是否均匀。

用于显示器测试的纯色

预览的初始色值为 #FFA500。进入全屏后，当前颜色会铺满测试区域。
