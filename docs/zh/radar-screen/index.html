使用方法

  1. 需要定格某个扫描角度时，先在工具区点击「暂停」。
  2. 点击或轻触预览画面，也可以选择「全屏」。
  3. 录制时可以等扫描线划过亮点，再在同一次转动中切入旁白。
  4. 点击或轻触画面或退出图标即可退出。使用键盘时也可以按 Esc。

关于工具

圆形视野里有同心刻度、固定目标点和旋转扫描线。扫描线会依次经过各点，退出全屏后可在页面控制区暂停或恢复。

常见问题

雷达上的光点代表真实目标吗？

光点和扫描线都是预设动画。页面不会接收外部雷达数据或定位信息。

暂停后打开全屏会保持完全相同的角度吗？

暂停状态会保留。全屏和预览分别绘制扫描动画，显示的角度可能不同。

为什么全屏时还能看到浏览器栏？

浏览器允许原生全屏时，画面会铺满屏幕。无法启用原生全屏时，画面会填满当前可视区域，浏览器栏可能仍在。点击、轻触画面或按 Esc 即可退出。

适用场景

航空和海上主题布景

把雷达放在录制现场的辅助屏幕上，为航空或海上主题布景加入运动。

展台控制面板

全屏放到展台的次要屏幕上，用持续旋转的扫描线表现设备正在运行，主屏留给演示内容。
